# NIFTY100_ETL – Financial Analytics Project

## Overview

The NIFTY100_ETL project is an end-to-end financial analytics pipeline that extracts, transforms, analyzes, and visualizes financial data of NIFTY100 companies. The project provides automated KPI generation, financial screening, peer comparison, radar chart visualization, and an interactive Streamlit dashboard.

---

## Objectives

- Build an ETL pipeline for financial datasets
- Calculate financial ratios and KPIs
- Generate CAGR and profitability metrics
- Develop configurable financial screeners
- Perform peer comparison using percentile rankings
- Visualize company performance with radar charts
- Build an interactive financial dashboard
